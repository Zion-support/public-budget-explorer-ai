# Public Budget Explorer AI

Natural-language exploration and visualization of municipal budgets and public spending — ask questions, detect anomalies and generate transparency reports.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- Ask questions in plain language over open budget data
- Automatic charts, comparisons and year-over-year trends
- Anomaly and outlier detection in spending
- Transparency report generator (PDF/HTML)
- Open-data export (CSV/JSON)
